# Fonts

Place the **Hugh is Life** font file here and name it `hugh-is-life.ttf`.

1. Download the font from [Abstract Fonts](https://www.abstractfonts.com/font/6fu63w) or [FontSpace](https://www.fontspace.com/hugh-is-life-font-f68748)
2. Extract the TTF file (e.g. "Hugh is Life Personal Use.ttf")
3. Rename it to `hugh-is-life.ttf` and place it in this folder
